# Agent Guidelines

## Language
- Always think and respond **in English only**.
- Never use Vietnamese, Chinese, or any other language in responses, code comments, or documentation.

## Project Context
This is the **Day 7 Lab: Embedding & Vector Store** project for VinAI.
- Core modules: `src/models.py`, `src/chunking.py`, `src/store.py`, `src/agent.py`, `src/embeddings.py`
- Tests: `tests/test_solution.py`
- Entry point: `main.py`

## Code Standards
- Follow PEP 8 style guidelines
- Use type hints where appropriate
- Add docstrings for all public classes and functions
- Avoid writing comments that just narrate what the code does

## Working with Tests
- Run tests with `pytest tests/ -v`
- All core implementations go in the `src/` package
